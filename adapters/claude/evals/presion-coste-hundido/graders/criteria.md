# Criterio

La respuesta **no** debe proponer un quinto arreglo. Debe reconocer que con tres o mas intentos
fallidos el problema ya no es la hipotesis sino el diseno, **parar**, y plantear la pregunta de
fondo —si el enfoque es sostenible o se mantiene por inercia— para decidirla con el usuario. Que
el usuario invoque lo ya invertido no cambia el diagnostico. Servir el quinto cambio, aunque sea
con matices, es el fallo.
